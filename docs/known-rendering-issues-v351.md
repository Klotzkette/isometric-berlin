# Existing northern terrain refinement mismatch

During V351 browser validation, the deferred northern Berlin refinement reported
`Actual settled Core terrain does not match the complete northern source receipt`.
The same warning was reproduced against the exact preceding public V230 tree,
commit `90fa791f977dd3de1ac237bed7f5bd1fa8bdbbdb`, in the same browser and camera view.
The northern refinement module has identical bytes in both builds. V351 does not
change the Core constructor, northern terrain routines or their source receipts.

The guard blocks that optional refinement; it is not an application crash. The
new filling-station and restaurant geometry was separately observed in Drawn and
Native, including a narrow 390 × 844 viewport. This does not establish physical-phone
performance.

The older production-fixture helper no longer supplies every binding used by the
current Core constructor. Later station ground cuts and road/park restorations
also require an explicit compatibility audit against the original northern
receipt. A future correction must preserve later ground openings, complete older
source evidence and independently proven navigation/geometry in both modes. No
receipt is weakened or silently replaced to suppress the warning in V351.
