published. It does not change the released model, build, archives or Pages tree.

the 16° views and 89 km for the native 66° view.

## Native subpixel and depth evidence

A separate isolated scene used the actual released native constructor and the
final composer output after SMAA. At BER, Minecraft, 66°, distance 18,501.288 m,
568×224 CSS **and device** pixels (DPR 1), the tower head is 0.2982968 CSS pixel
wide. All eleven phases from 0 to 1 pixel in 0.1-pixel increments produced
nonzero tower pixels: 3–6 pixels, with maximum RGB differences of 9–80 levels
from the uniform sky. Corner colour was `(183, 229, 242)`, alpha 255. This
measures the original tower and coverage companion together.

With an opaque foreground blocker, toggling the companion changed exactly
zero pixels over the entire canvas and the tower region; maximum RGB delta
was zero. The companion therefore did not leak through that blocker. These
controlled measurements are separate from the small full-city screenshot.

## Shelter placement limit

The full-city view reveals a small sub-metre overlap between a tree trunk and
the roof edge. The reference supports a continuous roof and a pine beside the
wall, but does not establish the catalogue identity or a corrected tree offset.
This remains an unresolved source-placement detail; no tree removal, roof notch
or source relocation was introduced. Pale native vertical posts match existing
tree bark and source cells, rather than a surviving old building owner.
