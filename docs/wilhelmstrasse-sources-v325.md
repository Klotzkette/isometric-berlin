# Wilhelmstraße: complete street audit and finite additional fronts (v325)

The audit follows the actual retained OSM Wilhelmstraße from Reichstagufer /
Marschallbrücke to Hallesches Ufer / Mehringdamm, approximately 2.407 km. Its
71 named OSM segments include road, service and pavement branches; they are not
invented as a single straight line. A 55 m search band identified 151 complete
existing source families / 612 leaves. This band is **inventory only**, never a
retirement, facade, body or navigation mask.

The retained evidence is `geo_data/regierungsviertel/wilhelm-street-v325-evidence.json.gz`.
It includes the complete inventory, current public OSM address responses and
request hashes, the selected complete source families, actual independent
constructor captures and exact ownership checks. Street addresses help identify
public buildings; a shop's postal label does not replace measured ownership.
Existing ARD, parliamentary, embassy, ministry and Mall models remain protected.
Wilhelmstraße 60 A/B already has its Linden-corridor treatment and is not
misclassified as an untreated front.

unrendered envelope. Whole rectangles, including all corners, must fit the full
source polygon and its holes. Existing paint, roof, court and navigation owners
remain intact. None of the selected owners overlaps V320's 200 improved fronts,
