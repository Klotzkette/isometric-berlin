# Fifty ordinary-building groups — V320

This finite pass differentiates 50 retained ordinary residential street groups:
200 distinct source owners, four per group, with 28 groups inside and 22 outside
the S-Bahn Ring. Every owner has a represented drawn front and independently
verified cardinal native spans. The selected groups are not a district expansion
or an assertion that every building in those neighbourhoods is complete.

The inherited full street-wall extents and vertical levels are source geometry.
Window divisions, storey/bay fitting pitches, neutral wall tones, recess depths,
frames, crossbars, sills, base courses and eaves are **contextual display
estimates**. References document local architectural character; they do not
survey each selected house's present paint or apertures. Older reference photos
are not presented as evidence of a current tenant, entrance or restoration.
No roof, dormer, balcony, ornament, sign or entrance is invented. Reference image
pixels are not included in the viewer or requested while it runs.

## Exact source and replacement contract

- All original public packets are unchanged. Each input's full bytes and SHA256
  match published v1.0.199 (`e594dfff933c7a0114d3f58ac7c2d28872e612a2`).
  Older V188/V230 full immutable SHA receipts are separately reconstructed by the
  existing strict historical reader. A later published packet may contain
  legitimate additions; the ledger explicitly records when its decoded payload
  differs from an earlier historical snapshot.
- Old V188/V230 fronts are selected only from immutable ordinary-wall receipts
  with complete unoccluded old grids and a positive independent native reading.
  Their complete old pane/course triangle **multisets**, including every
  quantized XYZ and RGB word, must replay exactly. Missing, duplicate or foreign
  fitting words reject replacement. Retirements name only generic fitting parts;
  no source body, roof, court, mapped door or unrelated index is retired.
- New-only primary fronts have no older generic fitting receipt. They require a
  positive ordinary-residential/mapped-material/protected-owner audit, complete
  actual generic wall faces, the selected owner's exact source edge and vertical
  datum, and independently verified actual native wall coverage. They append
  fittings without claiming any old pane retirement.
- Already authored fronts and later named-source owners are excluded. Mapped
  colours/materials win. A restrained wall skin qualifies only on a complete
  actually delivered ordinary wall with the retained generic RGB. The old body
  remains behind it. Rounded skin vertices clear the source plane by at least
  2 cm. Existing mapped V233 entrances retain exact objects and paint: the new
  skin/base has their aperture complement, and intersecting window cells are
  omitted. Thus no new opaque pane crosses a mapped entrance.
- Glass lies behind projected frames; four actual reveal returns and projecting
  sill tops make the depth readable. New stock vertices are shared only when all
  position and RGB words match. Expanded triangle words and winding are exact;
  the existing packet material uses flat face shading.
- Both families use the established closed V300 capture/prepare/retire lifetime.
  Capture precedes older preparation; append follows all existing quarter
  tickets. Exact raw/prepared navigation and line guards are finalized using
  the actual Bun predecessor/quarter pipeline. Original input objects, old
  typed-buffer prefixes, navigation, lines and unrelated indices remain intact.
  The main viewer explicitly supplies the weak catalogue to the existing serial
  streamer; core workers that do not render these fronts retain no duplicate
  catalogue. Unknown/changed/foreign/stale sources keep the existing original fronts.

All geometry stays in the current streamed tile and its existing vertex, index,
part, CPU/GPU residency and fetch budgets. Full drawn detail is shared by touch
and desktop. Native faces and every new native triangle remain cardinal; they
are not a rotation of the drawn model. No texture, timer, extra coverage, tour
stop, model parameter or renderer-quality limit changes.

## Reproduction and checks

Run from the repository root:

```sh
uv run --no-sync python -m scripts.build_cluster_facades_v320 \
  geo_data/regierungsviertel/cluster-facades-v320-west-profile.json \
  geo_data/regierungsviertel/cluster-facades-v320-north-profile.json \
  geo_data/regierungsviertel/cluster-facades-v320-south-profile.json
bun --bun src/app/scripts/hash-cluster-facades-v320.ts
uv run --no-sync pytest -q tests/test_cluster_facades_v320.py
```

The compiler rejects any missing group/owner or one-sided model. The full
production contract test separately exercises the real old pipeline and both
independent decoder families, comparing original source/buffer complements,
closed admission, exact generic retirements, new append bytes and unchanged
navigation/lines. Package sizes, full-city performance and final publication
checks belong to the release record; this source refinement claims no measured
PC frame-rate improvement.
