## Public architectural references

The sources below establish the public exterior recognition cues. No image pixels or photographs are shipped. Window pitches, member widths, reveal depths and small material tones are explicitly reference-guided display estimates; they are not a facade survey. The current directory's photographs of several Bonn seats are not used as Berlin references.

- **BMI:** [Müller Reimann, completed extension](https://www.mueller-reimann.de/projekte/erweiterungsbau-bundesministerium-des-innern), including the limestone facade and deep window reveals; project photographs credited to Stefan Müller. The measured existing main family remains authoritative.
- **BMJV:** [BBR public building history](https://www.museum-der-1000-orte.de/liegenschaften/liegenschaft/bundesministerium-der-justiz) and [Berlin monument record 09095926](https://denkmaldatenbank.berlin.de/daobj.php?obj_dok_nr=09095926). The seven arches and paired Tuscan supports are public street architecture. Their small member dimensions are interpreted, within the complete source colonnade footprint.

The remaining eight already authored ministries receive no replacement.

## Reproduction and validation

The source archives under `geo_data/regierungsviertel/raw/lod2/` remain unchanged. Their source is [Geoportal Berlin LoD2](https://gdi.berlin.de/data/a_lod2/atom/), under dl-de/zero-2-0; archive and sheet identities are recorded in the evidence.

The offline CLI `src/app/scripts/capture-federal-ministry-sources-v321.ts` accepts a fresh absolute external output directory and `all`, `drawn`, `native`, `preview` or `central`. It bundles the actual retained constructors, evaluates real ThreeViewer options, runs the complete native city/sites/client preparation, and captures both Bun/JSC and Node/V8. Native full and touch jobs are strictly sequential and disposed before the next job. It never writes a product file. Native captures represent the historical source-constructor/parking witness, not a V201 startup timing claim.

Then run the finite compilers and finalizer:

```sh
uv run --no-sync python scripts/finalize_federal_ministries_v321.py --capture-dir /absolute/new/capture-directory
uv run --no-sync python scripts/build_federal_ministry_packets_v321.py
bun src/app/scripts/hash-federal-ministries-v321.ts
```

The finalizer writes only the new V321 derivatives; it does not repack an original public packet. Python geometry/source tests and the Bun actual packet/private-lifetime tests accompany these files. The separate full-world startup probe uses the actual V201 order: constructor → required sites/client corrections → Rosengarten → government models/late transfer → instance parking → upload. Parking-before-transfer is an adversarial rebind case and is not presented as startup evidence. CPU timings do not claim GPU time or a total PC frame-rate guarantee.
