# Hospital architecture v308

This finite refinement covers the existing Bundeswehrkrankenhaus Berlin,
Vivantes Klinikum im Friedrichshain at Landsberger Allee 49, Charité Campus
Benjamin Franklin and the upper treatment block of Charité Campus Mitte.
“Vivantes” is resolved against the existing v228 campus and the operator's
July 2026 plan. It does not assert a survey of every Vivantes hospital.

## Measured envelopes and retained evidence

The original official CBF archives are available again. The source receipt keeps
all 32 CBF leaves and 372 wall/roof sheets, plus all 37 Friedrichshain parents,
100 leaves and 996 sheets. Original archive hashes, original source sheets,
source XZ, court holes and old raw city packets remain unchanged. Every exact
old outside footprint fragment remains an explicit complement in the new model.

One CBF leaf, `DEBE3Dklzwy5PFJG`, contains an automatic gable spanning several
real flat roof levels. Only that exact leaf has a separate correction. Its
complete original sheets remain in the source receipt and the correction
receipt. Independently queried official bDOM samples, the official spring 2025
orthophoto and the mapped old upper parts divide its roof into finite regions.
Each region uses its own recorded observations. The low remainder has a separate
bounded observation set. The other 31 CBF leaves retain their original source
geometry. No campus-wide flat height is substituted.

The ward roofs are approximately 75 m NHN and the exposed lower blocks about
52.3 m NHN. The existing CBF display datum remains 3 m; the source family receives
one common translation. In Friedrichshain each complete parent retains its
actual earlier street/terrain datum from the delivered raw navigation. Earlier
v182 park placement offsets are recorded rather than silently dropping raised
buildings to 3 m or shifting the terrain again.

## Drawn, native and navigation

Drawn mode contains all corrected source sheets plus source-clipped openings,
reveals, paired panes, sills and rails. Touch devices use identical detail.
Native mode has independently compiled half-metre body/roof cells with exact
unions of equal adjacent intervals. Native openings and trim are cardinal;
they are placed on actual exposed body cells. For retained BWK/Charité bodies,
the compiler reads the actual delivered native wall polygons, excludes the v215
retired gable and requires every new member to fit wholly on a real outward
wall. Charité's retained treatment blocks use the original four-metre core
columns. No analytic rotated panel is passed off as native geometry.

Navigation uses each source leaf and its actual roof triangles, with all court
holes, plus the exact merged native cap rectangles. Native support includes
the rendered 5 cm cap; height never falls back to a whole-campus box. BWK and
Charité additions leave their existing body/navigation contracts untouched.

`HospitalArchitectureV308.ts` exposes `createHospitalArchitectureV308` and the
private `hasCompleteHospitalArchitectureV308` admission. The proof binds actual
children, complete geometry, attribute/index storage identities, instance
counts/matrices/colours, exact local poses/update policy and known
day/night/Schwellenraum materials. Authored disposal of an owned geometry, material or
instance resource invalidates the proof. Public flags,
partial roots, detached children or arbitrary material clones do not admit it.
Legal lossless GPU parking remains compatible. Failed construction disposes all
unpublished resources.

`applyHospitalPreviousV308` defaults closed. Only a fully attached privately
admitted replacement can hide exact old CBF/Friedrichshain v228 batches or zero
the exact old BWK wall rows. All foreign BWK rows/colours remain byte-identical.
Missing, damaged or evicted replacement restores the owned old rows and batches.
Late lazy admission also accepts already graded, interleaved and legally parked
actual old constructors. Exact per-component word bytes are hashed in original
vertex order rather than hashing an interleaved backing wholesale. A preexisting
Schwellenraum grade is admitted only through the material factory's private
object/day/grade provenance; a public marker or arbitrary cached clone fails.

After the first complete canonical word audit, an applied legacy transaction uses
private attribute/storage identities, versions, local/ancestor poses, source
material provenance and resource lifetime receipts. Periodic presentation sync
never rehashes the large source batches. Changed backing, versions or poses
close the transaction and restore its exact prior rows; an explicit later
reapply must pass the full original audit again. The twelve separate-task real
constructor/interleaving/parking benchmark fell from22.53/56.88ms drawn/native
to0.111/0.048ms mean per applied sync. The large parked matrix is not read.

Only a private readonly scope opened by the actual eligible scene GPU residency
manager can qualify geometry/instance `dispose` as a reversible GPU retirement.
Those events preserve the unchanged CPU source and permit identical reupload.
Authored/manual geometry, instance or material disposal still invalidates private
admission; public tags cannot grant an exception. Actual manager retirement,
reupload, manual rejection, changed storage/version/pose and restored legacy
rows are exercised in `hospital-lifetime-fastpath-v309.test.ts`.


## Packet integration contract

`hospitalArchitectureV308Packets.json` has eight required-replacement plans:
drawn/native for `8_-2`, `9_-2`, `outer187--8_16`, `outer187--7_16`.
All are bound to the identical v195 raw/prepared predecessor, using the existing
v303 packet engine. There is no append mesh: the complete required model owns
the new body. Only exact old source body triangles, roof ink and matching old
navigation records retire. Foreign packet geometry, roads and owners survive.

The earlier v182 park placer assigned some shared boundary walls/roof lines a
neighbour's offset. The finite exception receipt matches the complete XZ and
relative-Y topology to a unique actual predecessor face/segment, and requires
a known original raw-navigation offset. No broad spatial mask or guessed
missing triangle is accepted. All such occurrences are listed in
`hospitals-v308-packet-evidence.json`.

Root composes overlapping v306/v307/v308 plans offline into one atomic
transaction per physical tile, preserving the identical predecessor pins and
disjoint retirement indices. Every involved complete-model gate must pass.
An incomplete replacement retains the complete old tile.

Root registers `hospitalArchitectureV308Core.json` field `sites` as weak
construction data. The strong profile contains only finite navigation/source
receipts. The local member codec preserves canonical Float32 input bits through
sorted opaque-member columns and integer delta/zigzag varints; it does not
reduce geometry, detail, resolution or view distance. Native construction does
not decode drawn source arrays. Existing runtime/package ceilings, modes and
93 tour stops are unchanged.
