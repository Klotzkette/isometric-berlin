# V322 source storage and live admission

The eighty finite ordinary eager fields in `src/app/losslessEagerFieldsV322.ts`
are pinned against the exact published v1.0.201 source graph and field values.
The change encodes their immutable source literals through the existing gzip
codec; it preserves every decoded value, signed zero, writable data property,
strong ownership and named/default alias. Existing weak/lazy tables and every
older source payload remain unchanged. Separate production transformations
verified all values and metadata-only tree shaking. The sum of minified source
literal savings is 2,962,053 bytes; this is not a promise about a particular
network transfer time.

Four exact native-only AltMitte mesh fields (packets 041, 042, 043 and 071) are
explicit gzip/Base64 exceptions to the usual packed-packet literal rule. Their
complete packed strings remain exact and eagerly strong. Each decoded JSON
field is smaller than 840 KiB; evaluation follows the existing sequential
native preload. No new decoder belongs to the initial bootstrap or geometry
Worker, and metadata-only imports eliminate this new decode work. All other
packed packets keep their previous encoding.

New university and theatre constructor data use the existing lossless packed
word formats and audited construction caches. Their new streamed recipes have
the existing per-packet weak lifetime. The original eager navigation and source
records remain strong; no older cache lifetime is reclassified.

The complete original native RLE source can have multiple vertical intervals
in one cell. Exact binding now retains the full five-word signatures, requires
every original interval and every positive-area contributor, and refuses
retirement of any mixed foreign cell. Live source topology is pinned for all
selected row lists of a multi-interval plan. Full matrix/colour/outside words
and original rollback references remain required.

The Viewer reads office and university readiness in one complete status check
per relevant checkpoint. Surrounding residents share that result instead of
repeating the same source validation; unrelated residents need no such poll.
Navigation first rejects points outside the actual completed render bounds,
with a conservative margin for display rounding. A positive candidate still
requires every existing private source/model gate. There is no timed cache or
shortened admission test. New Archenhold roof support is an interior floor
query with a current-height hint; it never replaces the terrain beneath its
open instrument cover.

The 894 MiB uncompressed package ceiling and all bootstrap, Worker, serial
decode, prefetch, scene residency and upload budgets remain unchanged. Full
drawn touch detail and independent native geometry remain available.
