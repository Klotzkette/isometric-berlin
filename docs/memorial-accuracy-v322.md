# Public memorials, Maison de France and the sculpture boulevard — v322

This is a finite public-reference interpretation. Original source records,
building envelopes, cemetery footprints, earlier complete architecture and all
unrelated geometry remain. Small sculpture curves, facade fittings, portal
arrangements and material tones are display estimates, not surveyed meshes.
No reference photograph pixels, texture requests, grave inventory or military
interior is added.

## Source admission and reversible ownership

`capture-memorials-v322.ts` runs the actual unchanged legacy constructors in
both JavaScriptCore/Bun and V8/Node. Instrumented EastParks ownership tags are
external evidence only: every full emitted attribute, index, matrix and colour
stream is compared with a separately unmodified constructor before selecting
any relief row. The two engines produce identical component words. The
finalizer verifies every captured original file SHA before writing the new
literal catalogue.

`MemorialPreviousV322` issues private plans only after the actual selected old
source is admitted. Berlin and Pyramide use the already loaded real street
entry and terrain sample. Schönholz preserves the original weak getter and
three small source rows without retaining the large consumed park payload.
Treptow binds all16 actual source cenotaph records. Native-first public art and
new additive Allied markers use their retained, literal-pinned compiled author
sources; these cannot authorize a fictitious old-body or voxel retirement.

Berlin and Pyramide share one composed Drawn transaction on the actual old
monument family. Cadillacs/French/British are additive. Schönholz owns its exact
separate NorthParks transaction. The live Treptow transfer is composed with
Archenhold by the EastParks controller because the Native13:7box host is shared;
two independent transactions on that host are prohibited.

Complete replacement geometry and matching granular solids precede publication.
An explicit activation binds the actual family parent. Missing, changed,
partial, duplicate or foreign input, cancellation, a changed pose, hidden or
detached model, changed typed storage/draw range or authored resource disposal
closes the model and synchronously restores the complete old outside complement.
Legitimate shader/GPU retirement follows the existing private lifetime markers.
Ordinary release restores old buffers before disposing the new site.

Private per-site collision bounds reject distant queries before any source or
geometry check. Within them, the full model/source gate remains. The old
Schönholz three-box sculpture and the two old generic boulevard markers have
no separate old navigation volumes; no geographic carve is required. Original
park terrain, obelisk/building collision and all unrelated navigation remain.
Maison changes fittings only and keeps the original source navigation.
