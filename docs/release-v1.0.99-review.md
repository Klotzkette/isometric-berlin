# v1.0.99 — Funkturm, ICC and Friedhof Grunewald-Forst

Step 10, limited to the three requested places inside existing coverage.
The 93 tour stops, other buildings and landscape detail, navigation controls,
view distance, mode behavior and CPU/GPU residency budgets remain unchanged.

## What changes

- Funkturm: additional foundation/bearing detail, visible stairs, broad
  restaurant canopy and inclined window register, upper rails and antenna
  fittings. The full earlier steelwork remains. Two documented degenerate
  residual proxy walls are removed, without changing unrelated packet faces.
- [ICC](icc-v199.md): 49 official measured parts and 671 retained original
  wall/roof sheets, silver-grey cladding and glazing registers, exterior
  curved-profile ribs and triangular beams, entrance details. The exact
  source skyway arm is opened below and connected at the western-hall level;
  the old ground-to-main-roof extrusion is an explicit source conflict.
- [Grunewald-Forst](cemetery-grunewald-v199.md): exact mapped cemetery boundary,
  22 interior paths, an open arched entrance, mapped benches and grave anchors,
  with Nico and Margarete Päffgen's dark marker at the retained OSM position.
  Additional anonymous sector markers are illustrative, not a burial register.

All new photographic references are permitted Commons files with mirrored
credits in the existing closed source menu. Photographs are not bundled.
Metric evidence and estimated fine details remain distinguished in the docs.
The old source inventories are retained with preservation receipts; exact
obsolete proxies are transferred, never hidden as a performance reduction.

## Memory and modes

The factories allocate only their selected drawn/native family, with final-sized
buffers and no image textures. Constructor source arrays use the audited weak
cache; compact independent collision metadata remains available. Actual factory
reconstruction after simulated collection compares every attribute and material.
There is no claim of zero memory cost for additional detail or universal freedom
from operating-system termination on every physical phone.
