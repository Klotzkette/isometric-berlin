# Rotating flight starts (v232)

Ordinary launches cycle through Bundeskanzleramt, Brandenburger Tor, Richard Serra's Berlin Junction, Berlin Hauptbahnhof, Kaiser-Wilhelm-Gedächtniskirche, Rotes Rathaus and Neue Nationalgalerie. Berlin Junction keeps the existing Berliner Philharmonie catalogue alias. The five featured rail stops and the 93-stop tour are unchanged.

The chosen name and flight pose are evaluated once when the App module loads. React remounts, visual-mode changes and clean renderer recovery reuse this seed; an available navigation snapshot takes precedence. Walking remains opt-in. Explicit place hashes are resolved before the rotation and do not consume it. Theme-only links keep their requested mode. The two additional start-only names also resolve when following or copying a place link; their selection metadata contains no map coordinates or artificial tour index.

The existing small last-start key is retained. Persistence uses same-tab history, then session storage, then local storage for reading, and updates every available store. Access failures are caught, including throwing storage getters. The history fallback merges unrelated state and does not change the URL. This prevents consecutive reloads from repeating even when local storage is blocked. When every persistence mechanism is denied, a valid start still works and remains stable for that launch; continuity across a completely new page cannot be guaranteed without any permitted persistence.

Existing public-approach cameras retain their direction and apparent framing using the ordinary 16-degree flight lens and its existing dolly compensation. The gallery pose is exactly the v223 flight pose. The two additional targets use the already committed Gedächtniskirche ruin centre (OSM way 15218373; `gedaechtniskircheRuinProfile.ts`) and Rotes Rathaus clock-tower centre (LoD2 parent DEBE3DgmfpurHZfT; `alexanderCivicProfile.ts`). Camera elevations and approach positions are presentation choices, not new survey measurements. No geometry, catalogue data, textures or residency limits change.

Focused tests exercise seven-place cycling, storage failures, history-state preservation, all explicit catalogue/start-only links, all six theme links, camera equivalence, the production initial-navigation handover, recovery priority and repeated App renders without an additional rotation.
