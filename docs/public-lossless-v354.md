# V354 public storage offset

The complete public viewer retains every existing same-origin city packet and all six visual modes. Its packaging-only overlay re-encodes 381 exact, previously unchanged gzip packets with `@gfx/zopfli 1.0.15`, one iteration. The complete decompressed bytes are compared, not only mesh counts or selected fields. Repository source packets and the offline package keep their existing representations.

The packets save **2,790,988 bytes**; the manifest saves another 11 bytes. Only each selected descriptor’s compressed `bytes` and `sha256` fields change. Paths, bounds, decoded sizes, geometry, textures, navigation, runtime quality and memory limits remain fixed. The staged manifest is reversed and compared to the complete predecessor to prove that unrelated fields are identical.

Selection pins, all before/after SHA-256 values and per-packet equality results are retained in the V354 release workspace. Before publication, the complete staged tree must remain below 1,000,000,000 bytes and every changed packet must pass exact HTTP verification. Both full downloadable archives are checked independently against the offline folder, path by path and byte by byte.

Three U-Bahn approach packets are explicitly excluded because their terrain/access
admission checks compressed descriptor bytes. Their original public descriptors
and gzip forms remain identical. The same exclusion applies to future selection
in this release helper; no runtime admission guard is relaxed.
