# Berlin detail pass V346

The release combines actual missing mapped territory with source-bound corrections
inside the existing city. It does not erase any previous mode, place, source file
or mobile detail. All 2,906 previous city descriptors and complete packet bytes
remain identical; 83 new Kladow/Gatow and Tegel tile pairs add 19,181,100 bytes.

- **Kladow/Gatow:** 9,775,054.6 m² of genuinely absent coverage, 12,399 complete
  official source families, 15,299 leaf parts and 137,744 measured sheets.
  Of those, 12,360 have positive newly rendered Drawn area; 39 only touch the
  boundary. Native uses its established two-metre grid (12,021 represented
  families), without inflating sub-cell sheds or narrow boundary remnants.
  Current runway remnants, hangars, aprons and existing residential development
  are retained; no historical full runway is drawn across Landstadt housing.
- **Tegel/Tempelhof:** exact currently mapped apron polygons and disused taxiways;
  Tempelhof's concrete apron replaces only the wrong basic ground material,
  preserving outside ground, heights, paths and all old airport geometry.
- **Principal roads and side streets:** 3,503 houses in 473 existing tiles with
  current mapped storey counts and complete independently checked wall support.
  [Method and limitations](main-road-fronts-v346.md).
- **Wollankstraße:** five measured Rettigweg residential fronts with four/five
  mapped storeys and separately matched Native walls.
- **Huxleys:** glazed doors, upper lights, slender sign and open shallow glass
  canopy on the actual eastern parking-side wall. [Registration](huxleys-entrance-v346.md).
- **Hellweg and Humboldthain:** complete measured Hall/entrance-building bodies,
  retaining earlier source geometry, station bridge and staircase context.
- **Schwanenwerder and Pfaueninsel:** complete measured villa roof families,
  palace clock turret/zinc dome, cornices and iron bridge detail, with matching
  height queries and host lifetime. [Island evidence](islands-v346.md).

This is a finite improvement pass, not a complete photo survey of every main or
side street through the city boundary. Unknown aperture dimensions/materials are
presentation estimates. Kladow uses the established outer-city ground datum;
this pass does not claim a new topographic survey of the entire locality.

New street-front recipes are split into thirty bounded lazy modules and retain
per-packet weak decoding. Existing live geometry, fetch, startup and Worker
limits remain unchanged. Every request resolves from the complete same-origin
public package; raw GitHub fallback is not used. Six modes, 93 tour stops and the
same full Drawn model on touch devices remain included.

The static manifest allowance now matches exactly 2,989 tiles and 2,934 footprint
polygons (4,023 KiB source ceiling). This is metadata only; no live or Worker
limit increases. The 27 appended ground polygons preserve all 31 holes and
provide the same 3 m outer datum during a mode-family reload, before the actual
resident packet height becomes available.

The original restored-road NDJSON remains unchanged in source. A build-only
transport compresses each of its 425 batches independently with the existing
gzip/Base85 codec. Selected additional JSON source modules use the same existing
Base85 encoding; decoded values, per-packet weak ownership and geometry stay
identical. This saves space without reducing model detail.

Release measurements: the complete offline folder contains 6,589 files and
1,225,122,455 bytes (1,169 MiB finite offline ceiling). The complete same-origin
Pages candidate contains 6,590 files and 995,629,913 bytes, below the unchanged
1,000,000,000-byte limit. Its 5,978 city packets include all 5,812 previous
packet files and 166 new files. The production Worker is 14,832,562 bytes,
below the unchanged 16 MiB limit.
