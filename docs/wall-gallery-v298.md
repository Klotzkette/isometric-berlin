# Preserved Berlin Wall locations and Mauerpark terrain, v298

Step 10 source-bound additions for East Side Gallery, Mauerpark and Topographie des Terrors. This module does not remove previous source geometry, expand city coverage, add a tour stop or start an animation timer.

## Represented evidence

* East Side Gallery uses all vertices of **seven present-day OSM wall polygons**, freshly read from relation 6807791 on 2026-11-02. Relocated pieces and actual openings remain separate. A historic/cartographic trace is not converted into a continuous standing wall. The atypical historical Hinterlandmauer made with Grenzmauer-75 elements is described by Stiftung Berliner Mauer and the Landesdenkmalamt.
* Eight named works occupy retained OSM artwork-node anchors, each within 9 cm of the corresponding current wall perimeter: Dmitry Vrubel, Birgit Kinder, Thierry Noir, Kani Alavi, Günther Schaefer, Gabriel Heimler, Thomas Klingenstein and Christine Kühn. Surface direction follows the actual street-facing ring course. The kiss has individual face, nose, ear, mouth, hair, wrinkle, spectacle, hand, collar and suit contours. Kinder's Trabant, Noir's head sequence, Alavi's crowd, Schaefer's flags, Heimler's jumping figure, Klingenstein's Japan composition and Kühn's hands use distinct authored drawings.
* The artwork is **independently authored flat polygon interpretation**, not a photographic texture, an exact facsimile or a complete inventory of all gallery paintings. Mural display widths and detailed contours are proportion estimates from the linked official visual references. No reference-photo pixels, canvases, image textures, external font or bitmap are shipped. The native world independently resolves these colour fields into cardinal block runs.
* Four existing source owners receive floor bands and glazing frames: Living Levels, Stream, Spreeturm and EDGE East Side. All retained footprint vertices and source envelope heights remain unchanged. Fitting placement follows the actual streamed render ground at Y = 3 m; original measured LoD2 ground values remain distinct evidence. Published 14/24/20/36-storey facts inform their subdivisions; measured and published height differences are documented rather than silently replacing the source height. These fittings do not reconstruct every setback or replace the original tower envelope.
* Mauerpark retains OSM way 449318658's actual **176.55 m** mapped legal graffiti wall, rather than stretching it to a rounded general description. Concrete panel/joint construction sits on the measured Sonnenhügel. The changing graffiti there is explicitly original illustration, without asserting that a particular anonymous signature is currently present. The retained amphitheatre crescent contains 297 individually placed granite seat members; the mapped circular stage and public approach remain open. The October 2026 northern-Sonnenhügel works are ongoing in the official account; no proposed 2027 outcome is presented as finished.
* Topographie retains the existing measured wall, damage, coping and exhibition. A reinspection of its already retained CC0 reference establishes a **horizontal cable protection fence**, not vertical pickets. Added thin cables and post connections use the existing guard course. No second copy of the preserved wall is added.

`wallGalleryDgmGroundAtV298(x,z)` exposes bilinear interpolation of the **15,142 unchanged DGM1 raster-centre samples**. Their `.500 m` UTM centres, EPSG:25833 axes and `scene Y = NHN − 30 m` datum are retained. Independent source lines include:

The finite display support is the source wall/amphitheatre hull plus a rounded 176 m allowance. Bounds are `[2034.4493867, −2868.6352070, 2468.3584011, −2350.6155468]`; area is 168,553.442 m². A 160 m smooth edge transition joins the earlier datum while leaving the actual mapped wall crest at full measurement weight. This interpolation extent is **not a surveyed parcel boundary**. On a two-metre verification raster the artificial weight gradient reaches 25.224% with the streamed 3 m baseline and 23.129% with the Core 5.2 m baseline; this is distinct from the actual DGM slope.

`wallGalleryHillGroundAtV298(x,z,native=false,baseline=5.2)` returns `null` outside its finite support. Drawn mode uses the same four-metre NW/SE triangles, anchored at the support's west/north bounds, as the packet draper. Raw blended DGM values define the corners. Thus the triangulated display is distinguished from unmodified measurement samples. Native mode first snaps XZ to the global four-metre cell centre, then applies the finite mask, source blend and 0.125 m ceiling. Outside that native cell support the original baseline remains exact. `wallGalleryHillDeltaV298` returns zero outside. Callers explicitly pass baseline 3 for streamed ground and 5.2 for Core ground.

`parkReliefAt` routes this field into existing world terrain/navigation sampling. The support list also bounds existing refinement helpers. The path sampler uses **source Y + new field − old 5.2 m datum**, preserving clearance rather than subtracting the new hill from an old path. Synthetic raster callers split only finite support intervals and retain all outside widths, old tops and colour ownership.

The reproducible `coreSupportAudit` checks occupied source geometry, not rectangular grid metadata. Although Core grid bounds extend into the support, **zero** occupied Core ground cells, LoD2 rings, native columns/trees, ParkDetails props/paths or smooth surface polygons intersect it. Sixteen source categories and five original file hashes are retained. Therefore `terrainPayload.ts`, `MinecraftVoxelWorld.ts` and `IsometricCityWorld.ts` need no object transforms or source-array changes here. The ground-run helper returns the untouched run when its broad support/apron contains no cell with a changed height. An actual native Core-buffer comparison, with and without the additional support, verifies identical instance count and identical matrix/colour SHA-256 values. Actual local ground and the Nord-Mauerpark v266 props are in the separately receipted streamed packets.

The terrain receipt records eight raw drawn/native packets (`3_-6`, `3_-5`, `4_-6`, `4_-5`), mesh field fingerprints, unchanged original navigation, affected original Y coordinates and exact Nord v266 prop records. Baseline ground there is 3 m; origin Y is −10 m. Only six drawn stone-edge members / 84 native edge cells in `4_-6` lie within the support. The `3_-6` benches and unrelated `alt-mitte-v169` mesh parts remain outside. Packet admission, complete outside complements and rigid complete-building/prop offsets are integrated by the root agent's `MauerparkTerrainV298Packets` workflow.

Admission uses an unexported Symbol and a private WeakMap token, so ordinary later shallow packet copies retain the receipt. All original encoded objects and field references remain unchanged during admission.

The preparer appends complete replacements before any old decoded destination index can be collapsed. Full-parent unions determine one rigid offset across tile cuts; every moved body keeps exact original XZ, face order, colours, dimensions and internal XYZ differences. Remaining non-ground connected props also receive one rigid offset for their complete component, including its outside faces. Independently decoded receipts verify 6,573 moved source triangles exactly.

`mauerparkTerrainExtraLineVerticesV298(chunk)` reserves a finite tail in the existing ink buffer. `applyMauerparkTerrainLinesV298(chunk,values,stride,appendStart)` runs **after all earlier line helpers**, with `appendStart = original line vertices + streetCurveExtraLineVerticesV276(chunk)`. The preceding street-curve helper receives only its original buffer slice. Source segment numbers remain stable; old kerbs split on the same four-metre grid/diagonal boundaries, building ink moves rigidly, and all outside portions and interpolated original colours remain. If a previous helper already retired an original segment, its new complete raised complement also degenerates, preventing resurrection of obsolete ink.

The final runtime recipe is 4,991,535 bytes uncompressed / 1,601,434 bytes gzip, with 49,197 bytes of compressed evidence. No photographic asset or new draw call is introduced. Final raw-source hashes are assessed on actual decoded fields; lossless gzip recompression need not preserve a container byte stream.

A bounded native-tower audit covers all 5,354 fitting boxes against the retained neighbouring building footprints: no box centre or complete XZ footprint intersects a different source building.
