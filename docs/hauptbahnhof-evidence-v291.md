# Hauptbahnhof interior evidence — Step 10, v291

Retrieved **1 November 2026**. The official station directory establishes
tenant names, floors and broad directions. The schematic station plan establishes
connections and level order. Neither is a measured interior survey: individual
shop bays, stair dimensions, door travel and lift coordinates remain explicitly
estimated display geometry. No photograph, PDF page, plan tracing or image texture
is distributed with this refinement.

## Public circulation

The [DB station plan](https://www.bahnhof.de/downloads/station-plans/1071.pdf)
shows five levels: deep platforms (UG2), lower shopping/concourse (UG1), street
concourse (EG), upper shopping/concourse (OG1) and elevated platforms (OG2).
The main exits are Europaplatz to the north and Washingtonplatz to the south.
There are three upper island platforms with six tracks, numbered 11–16, and
four lower islands serving tracks 1–8. The station's daylight openings remain
open across the stacked public levels.

The [S-Bahn Berlin equipment register](https://sbahn.berlin/fahren/bahnhofsuebersicht/hauptbahnhof/)

The [DB architectural account](https://www.deutschebahn.com/de/presse/presse-regional/pr-berlin-de/hintergrund/Berlin-Hauptbahnhof-Markantes-Eingangstor-zur-Stadt-8860186)

outages are not reproduced: the user expressly requests a continuously running
simulation, not live operational information. The displayed movement speeds,

earlier tables remain byte-identical and SHA-pinned in the new receipt.

Both independent model families use this same ground ownership. Replacing
the two prior runtime table imports with the single 133,505-byte table saves
82,352 bytes of raw source-table data before bundling. The established material
pair and terrain-complement renderer are reused.

Six new Python tests and the nine earlier atrium/north-cut tests pass. They
verify source hashes, exact retained records, unique cell ownership, every
outside triangle/perimeter, bounded footprint and reproducible generation.
A separate runtime check removed 12 sight-ray obstructions across both families
and verified 10,848 complement vertices against their exact source heights and
paint, with one shared material pair. Navigation and completed station-geometry
verification belong to the integration checks; these ground checks alone do
