# V348: restrained city materials

This is a presentation pass on the existing city, not a claim that every facade
has been photographically surveyed. The finite ground/water admission and the
BahnTower reference detail are documented separately.

The ordinary facade palette retains all twelve stable family assignments, and
the outer fallback retains all eight. Only unrecorded fallback paint changes:
mineral plaster, warm grey stone and muted clay replace conspicuous peach and
green casts. Explicit recorded colour/material tags, landmark palettes, roof
shapes, windows, courtyards and navigation keep their existing precedence.
Native has its own unchanged block palette. No additional texture, geometry,
draw call, owner lookup, downloaded packet or per-frame facade operation is
introduced by this palette adjustment. The current immutable source bridge
retains the complete previous implementation and protects unrelated sources.
