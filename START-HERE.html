Vollständige 3D-Version starten

Diese HTML-Datei allein ist nur die 2D-Notansicht. Für Gebäude, freie Kamera, Fußgängermodus und Minecraft starte zuerst den kleinen lokalen Server im entpackten Ordner.

Windows: OPEN-3D-WINDOWS.bat macOS: OPEN-3D-MAC.command Linux: start-linux.sh

Nach dem Download das ZIP zuerst vollständig entpacken. macOS: Falls nötig den Starter mit Rechtsklick → Öffnen freigeben.

Isometric Berlin

Kompatible 2D-Notansicht ohne Terminal. Für echte 3D-Geometrie den lokalen Server starten.

Echtes 3D öffnen (lokaler Server) Öffentliches Repository öffnen https://github.com/Klotzkette/isometric-berlin Aktuellen Viewer herunterladen

Direktsteuerung: Maus ziehen verschiebt. Shift+ziehen oder Modus „Drehen/Swivel“ dreht und kippt. Atlas/Cinematic/Lab ändern Kontrast, Bühne und Lesbarkeit.

Dies ist nur die 2D-Kompatibilitätsansicht. Für das maßstäbliche 3D-Modell unter Windows start-windows.bat öffnen, unter macOS/Linux python3 serve-local.py.
