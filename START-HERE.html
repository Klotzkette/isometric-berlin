3D öffnen / Open 3D

Deutsch · Lokal starten

Entpacke den gesamten Download. Starte dann OPEN-3D-WINDOWS.bat unter Windows oder OPEN-3D-MAC.command unter macOS. Auf Linux: sh start-linux.sh.

Falls macOS den Start blockiert: Rechtsklick auf die Datei, dann „Öffnen“. Alternativ im entpackten Ordner python3 serve-local.py ausführen. Benötigt wird Python 3. Der Browser öffnet die Stadt automatisch. Lass das Terminal offen, solange du den Viewer nutzt.

Ein Doppelklick auf index.html kann die Stadt wegen der Dateizugriffsregeln des Browsers nicht laden. Die Startprogramme richten den nötigen lokalen HTTP-Zugriff ein; ein Internetzugang ist danach nicht nötig.

English · Start locally

Extract the entire download, then run OPEN-3D-WINDOWS.bat on Windows or OPEN-3D-MAC.command on macOS. On Linux, run sh start-linux.sh. If macOS blocks the launcher, right-click it and choose Open. Alternatively, run python3 serve-local.py in the extracted folder. Python 3 is required. Keep the terminal open while using the viewer.

Opening index.html directly cannot load the city because of browser file-access rules. The launchers provide local HTTP access and open the browser automatically. No internet connection is needed afterward.
